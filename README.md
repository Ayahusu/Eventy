# Django REST API for Eventy App

## What is an Eventy?

Eventfy is an event platform where users can post about upcoming events or programs to raise awareness and invite attendees. It helps organizers connect with people who are genuinely interested in their events, while also enabling individuals to discover like-minded communities and feel more connected.

## API Endpoint 

- User API Endpoint
- Event API Endpoint
- Notification Endpoint
- Reservation Endpoint
